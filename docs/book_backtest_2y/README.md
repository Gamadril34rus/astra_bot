# Проверка «Простой книги торговли» на истории (2 года, 1h/4h)

Что здесь лежит:

- `summary.md` — итоги бэктеста стратегии `book_breakout` (пробой →
  ретест → подтверждающая свеча, правила из `Simple Trading Book_compressed.pdf`
  в корне проекта) за **последние 2 года** на таймфреймах **1h** и **4h**,
  пара BTC/USDT (Binance), стартовый капитал 10 000 USDT, риск 0.4% на сделку,
  комиссия 0.1% + проскальзывание 0.1%, одна позиция одновременно,
  без адаптивного снижения риска по просадке (чистые правила книги).
- `equity_1h.png` / `equity_4h.png` — эквити-кривые и просадка.
- Полные сделки и покильная эквити-кривая генерируются скриптом в
  `reports/book_2y/` (в git не входят).

## Как воспроизвести

```bash
# 1. Положить свечи Binance в data/ (формат klines):
#    data/BTCUSDT_1h.csv и data/BTCUSDT_4h.csv
#    Пример готовых данных: github.com/RonaldLu66/binance-btc-monitor (data/),
#    либо выгрузка GET /api/v3/klines?symbol=BTCUSDT&interval=1h|4h.
python scripts/backtest_book_2y.py --years 2 --capital 10000
```

Скрипт сам соберёт `reports/book_2y/`:
`summary.md`, `summary.json`, `trades_1h.csv`, `trades_4h.csv`,
`equity_1h.csv`, `equity_4h.csv` и графики.

Флаг `--use-risk-adaptation` включает адаптивное снижение риска бота по
просадке (в этом режиме при глубокой просадке входы приостанавливаются —
это защитный слой бота, а не правило книги).

## Вывод

На окне 2024-08-20 → 2026-08-20 чистые правила книги в текущей реализации
дают profit factor **0.80 (1h)** и **0.79 (4h)**, убыток −9.3% / −3.4% при
buy&hold +7.5% / +8.0%. Win-rate 33% / 21%, просадка 13.7% / 5.5%.
Стопы отрабатывают чаще тейков (107/53 на 1h, 37/10 на 4h) — ретест-сетапы
в текущих параметрах не окупаются на этом окне. См. детали в `summary.md`.

> Бумажная проверка на истории, без реальных денег. Прошлые результаты
> не гарантируют будущую прибыль.
