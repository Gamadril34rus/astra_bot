# SAR reproducible backtest package

**Purpose:** make the Parabolic SAR portfolio numbers independently verifiable.

This folder fixes the gaps in the earlier markdown-only note:

- exact cost model (bot fees + slippage)
- date range of candles
- trade count, winrate, profit factor
- runnable engine source
- CSV trades + equity curve (generated by the engine)

## Cost model (as in demo bot)

From `astra_bot/engines/cost_model.py` → `bingx_perps_cost_model`:

| Item | Per side | Round-trip |
|------|----------|------------|
| Taker fee | 0.05% (`0.0005`) | 0.10% |
| Slippage | 0.10% (`0.001`) | 0.20% |
| Funding | **0 in this script** | not applied |

Earlier chat runs that used **0.03% slippage** overstated returns. Use only numbers from this package for bot-comparable claims.

## Strategy rules encoded in the engine

- Indicator: Parabolic SAR `0.02 / 0.02 / 0.2`
- Timeframe: `1h`
- Symbols: `BTC-USDT`, `ETH-USDT`, `SOL-USDT`
- Entry: SAR side flip on closed bar, `min_prev_series = 0`
- Exit: price touches SAR (stop); no take-profit
- Sizing: fixed fraction of equity at risk to stop (`risk_per_trade`)
- Portfolio: skip signal if open risk sum would exceed `max_total_risk`
- No EMA / volume / hour filters (max-result BASE)

## How to reproduce

```bash
cd docs/research/sar_repro
pip install requests pandas numpy
python sar_backtest_engine.py --start 5000 --out sar_repro_out
```

Outputs in `sar_repro_out/`:

- `summary.json` — dates, bar counts, all profile metrics
- `trades_raw_signals.csv` — every SAR trade before portfolio skip logic
- `trades_risk_*.csv` — accepted trades with notional, pnl_usd, equity_before/after
- `equity_risk_*.csv` — mark points for equity curve

### Note on earlier chat figures (270k / 5.1M)

Those came from prior sessions with slightly different SOL history length and/or re-fetches.  
**This package is the source of truth going forward.** Re-run the engine to refresh CSVs; expect small drift as the live kline window moves.

PF is identical across risk profiles because risk only scales size; trade list and per-trade % are the same when the cap does not skip (here skipped=0).

## Limits

- Not walk-forward / OOS split in this script (can be added).
- Funding = 0.
- Stop fill model: `min(open, stop)` / `max(open, stop)` on touch bar — simplified.
- Not production ASTRA code path; research only.
