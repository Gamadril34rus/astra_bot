## Правила формата (жёстко)

1. **РЕКОМЕНДАЦИЯ** — да, но **только с цифрами-обоснованием**.  
   Запрещено: «я решил», «очевидно», «лучше так», «верим в edge».  
   Обязательно: ссылка на n / median / PF / arrival / costs_r / stop_pct из reports.

2. В **каждом** пункте строка **«что опровергнет рекомендацию»** —  
   конкретный факт (порог, знак, n), при котором владелец должен передумать.  
   Защита от влюблённости в свой драфт.

3. Порядок полей не менять.

```text
### N. <короткий заголовок>
- ВОПРОС: …
- ДАННЫЕ: … (только цифры / ссылки на reports/*)
- ВАРИАНТЫ: A / B / C …
- РЕКОМЕНДАЦИЯ: … потому что [цифры из ДАННЫЕ]; не «я решил»
- ЧТО ОПРОВЕРГНЕТ РЕКОМЕНДАЦИЮ: если … (конкретный порог/знак/n)
- ЦЕНА ОШИБКИ: …
```
