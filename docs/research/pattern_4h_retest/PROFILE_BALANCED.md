# DEMO Profile: Pattern Balanced (середина)

## Назначение
Демо/paper профиль под проверенные правила 4h-паттерн → ретест на младшем ТФ.
**REAL не включать** без отдельного решения владельца.

## Правила
| Параметр | Значение |
|----------|----------|
| Сигнал | 4h close breakout фигуры |
| Вход | 15m retest → иначе 30m → иначе 1h |
| Ретест | откат 25% пути к стопу + close в сторону сделки |
| Паттерны | falling_wedge, sym_triangle, rising_wedge, desc_triangle |
| Сессия | 16:00–06:00 МСК |
| Стоп | экстремум 4h-структуры |
| TP | высота фигуры |
| Тайм-стоп | 48h |
| Риск | **1.5%** equity |
| Плечо | ≤ 3× |
| Монеты | BTC, ETH, SOL |
| Издержки (учёт) | ~0.16% круг BingX |

## Ожидание (бэктест 4h→1h, ~2 года)
- PF порядка 2.5–2.7 на наборе из 4 паттернов
- MaxDD при 1% риске ~12%; при 1.5% масштабируется вверх
- Типичный выигрыш ~3 R → при 1.5% риске ~4.5% депозита на тейке

## Файлы
- `config/demo_pattern_balanced.yaml` — полный профиль
- `config/demo.yaml` — DEMO под BingX + risk 1.5%
