# «Простая книга торговли» — база знаний ASTRA

Структурированный конспект правил из книги (64 стр., скан-PDF в корне репозитория:
`Simple Trading Book_compressed.pdf`). Эти правила закодированы в коде:

- `astra_bot/strategies/book_breakout.py` — стратегия по разделу 3 (стратегии 1–7);
- `astra_bot/ml/market_understanding.py` — детекторы свечных форм раздела 2
  (`candle_spinning_top`, `three_white_soldiers`, `three_black_crows` и др.);
- `astra_bot/ml/research_engine.py` — события `book_*` для статистической
  проверки правил книги на истории (walk-forward + FDR, см. `models/research_hypotheses*.json`).

> Принцип ASTRA: правила книги — это **кандидаты в гипотезы**, а не истина.
> Research Engine должен подтвердить их OOS, прежде чем им доверять.

## Раздел 1. Психология (стр. 6–9)

- FOMO → иррациональные сделки по непроверенной информации (стр. 6).
- Покупка на хаях/продажа на лоях от FOMO — хуже потери капитала (стр. 6).
- Как избежать (стр. 8–9): время на исследование; надёжные источники;
  выигрывать всё время нельзя → стратегия должна «сопротивляться FOMO».
- В коде: ASTRA не входит сразу на пробое — только после ретеста (анти-FOMO).

## Раздел 3. Торговые стратегии (стр. 26–34)

Общий принцип **пробой → ретест → подтверждающая свеча**:

1. (стр. 28) Цена, отклонённая от декольте: только лонг, и только когда цена
   пробила зону декольте **и сделала ретест**. Ошибка — покупать сразу на пробое.
2. (стр. 29) Симметричный треугольник после роста: ждать пробоя выше
   предыдущего максимума; ретест + бычья свеча → покупка **на следующей свече**.
3. (стр. 30) Растущий клин (продолжение вниз): ждать пробоя предыдущего
   минимума, ретест с медвежьей свечой → продажа; **стоп выше предыдущего максимума**.
4. (стр. 31) Симметричный треугольник в даунтренде: после завершения
   паттерна и пробоя декольте → продажа; стоп на уровнях 1/2 (локальные максимумы).
5. (стр. 32) Медвежий флаг: ждать пробоя нижней границы → продажа.
6. (стр. 33) Консолидация после импульса: разметить поддержку/сопротивление,
   ждать выхода, ретест + бычий моментум (A) → покупка (B).
7. (стр. 34) Бычий флаг: вход только после пробоя предыдущего максимума;
   вход после A увеличивает стоп; B — медвежья (ретест), C — бычья (вход).

Реализация: `BookBreakoutStrategy` (long/short, stop за экстремумом ретеста,
target = высота консолидации от пробоя, анти-FOMO фильтр, RSI-подтверждение).
