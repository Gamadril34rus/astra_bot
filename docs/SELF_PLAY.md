# ASTRA BOT — Walk-forward self-play

Бот учится торговать **без депозита и без подглядывания в будущее**:

1. Загружается год истории OKX по BTC/USDT, ETH/USDT, SOL/USDT (1h).
2. Каждый бар бот видит только данные **до момента ставки** и выбирает
   инструмент/сторону по сигналам стратегий (momentum, mean reversion +
   baseline, чтобы равномерно покрыть историю).
3. Открывается виртуальная позиция на 5% виртуального капитала
   (2000 ₽). Дальше «живём» в реальном времени: ждём срабатывания
   тейк/стопа или таймаута (24 бара).
4. После закрытия бот **разбирает сделку**: что было с индикаторами,
   волатильностью, RSI, объёмом, и делает запись-«урок» с пометкой
   `win/loss` и рекомендацией (`SKIP_HIGH_VOLATILITY`,
   `EXIT_EARLY_OVERBOUGHT`, `WIDEN_STOP_LOSS`, ...).
5. Накопленные уроки (2–5 тысяч за год по трём инструментам)
   сохраняются в `models/lessons.jsonl` и используются как датасет для
   LightGBM (см. `scripts/train_historical.py`).

## Запуск

```bash
# Self-play на реальной годовой истории OKX (публичный эндпоинт, без ключей):
python scripts/self_play.py --days 365 --target-trades 3000

# Офлайн на сгенерированных барах (без сети, для отладки):
python scripts/self_play.py --offline-candles 4000 --target-trades 2500

# Через Telegram (только админ):
/train

# Через веб:
curl -XPOST 'http://localhost:8000/self_play?target_trades=3000&offline_bars=3000'
```

## Утренний отчёт в Telegram

`scripts/morning_report.py` читает `models/lessons.jsonl` и каждое утро
(по Москве) присылает админам отчёт о виртуальном счёте:

```
☀️ Утренний отчёт — 10.08.2026 09:00 МСК

🎓 ОТЧЁТ ОБ ОБУЧЕНИИ
Виртуальный капитал: 1 899,70 ₽
Сделок: 2097 (845 ✅ / 1252 ❌)
Win Rate: 40.3%
Profit Factor: 0.91
🔴 PnL: -100,30 ₽
Макс. просадка: 7.10%
```

Cron: `0 9 * * * python /app/scripts/morning_report.py`.
Требуются `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_ID`.

## Сколько это занимает

Self-play — это обучающая симуляция, а не реальные торги. Один проход по
году на 3000 сделок локально занимает **20–40 секунд** на Python. Если
подмешать LightGBM-обучение и сохранение модели, суммарно — несколько
минут, и столько уходит на «разогрев» при первом запуске.

Чтобы растянуть обучение «примерно на неделю», как вы просили, бот можно
запускать в ежедневном цикле: каждый день подгружаются новые бары,
self-play дообогащает `lessons.jsonl`, модель переобучается на ночном
окне. Это настраивается в cron/systemd, а не в коде — логика уже
поддерживает дозапись уроков в один файл.
