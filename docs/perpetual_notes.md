# Бессрочные фьючерсы: модель paper-контура

Бот торгует ТОЛЬКО бессрочными фьючерсами BingX USDT-M. Спотового контура
нет. PaperBroker — честная эмуляция перпов, а не «спот с плечом».

## Источники цифр

- Комиссии: Perpetual Futures Fee Schedule — тейкер 0.05%, мейкер 0.02%.
- Фандинг: расчёт 3 раза в сутки (00:00 / 08:00 / 16:00 UTC+8) по открытым
  позициям. Положительная ставка — лонг платит шорту, отрицательная —
  наоборот. Бирже деньги не уходят, это p2p-выплаты между позициями.
- Рыночные данные — публичные swap-эндпоинты:
  - свечи: `/openApi/swap/v3/quote/klines`;
  - контракты, тикер, стакан, сделки: `/openApi/swap/v2/quote/*`;
  - mark price + текущий фандинг: `/openApi/swap/v2/quote/premiumIndex`;
  - история фандинга: `/openApi/swap/v2/quote/fundingRate`;
  - открытый интерес: `/openApi/swap/v2/quote/openInterest`.
- WebSocket рынка: `wss://open-api-swap.bingx.com/swap-market`
  (подписка `{"reqType": "sub", ...}`, сообщения в gzip, Ping/Pong).
- Приватный REST используется только для чтения баланса фьючерсного счёта
  (`/openApi/swap/v2/user/balance`) — оценка капитала и команда /баланс.
  Live-ордера отключены: методы ордеров/позиций клиента бросают
  `NotImplementedError`, сделки исполняет только PaperBroker.

## Что эмулирует PaperBroker

- **Комиссии.** Дефолт — пресет `bingx_perps_cost_model()`: тейкер 0.05%,
  мейкер 0.02% (paper всегда считает себя тейкером), slippage 0.1% на
  сторону. Явно переданный `CostModel` / `fee_pct` / `slippage_pct`
  перекрывают дефолт.
- **Фандинг.** Начисляется на НОТИОНАЛ (от плеча не зависит):
  `fill × qty × rate × intervals`, где `intervals` — прожитые 8-часовые
  интервалы. Время детерминированное (бары × timeframe), реплей даёт те
  же цифры. Знак: лонг при rate > 0 платит (+), шорт получает (−).
  Реальная биржа списывает дискретно 3 раза в сутки — здесь
  пропорциональная аппроксимация, честная в среднем. Ставка — живая
  с биржи (движок обновляет каждый тик), fallback — 0.01% за 8ч.
  В сделке фандинг пишется отдельно (`ClosedTrade.funding`).
- **Ликвидации.** По живой mark price, изолированная маржа:
  `liq = entry × (1 ∓ (1/lev − mm))`. Стоп обязан стоять раньше
  ликвидации (проверка при открытии, иначе `ValueError`). Без mark price
  проверка пропускается (fail-closed). Исполнение — по цене ликвидации,
  причина закрытия — `liquidation`.
- **Маржа.** Изолированная: `margin_used = notional / leverage`,
  сумма занятой маржи не больше equity.
- **Нетто-безубыток** покрывает комиссии обеих сторон, slippage и
  накопленный фандинг.

## Сознательные упрощения (paper)

1. Фандинг — pro-rata по времени удержания, а не дискретные списания
   в 00:00/08:00/16:00 UTC+8.
2. Исполнение ликвидации — ровно по цене liq (реально чуть хуже:
   страховой фонд + extra-комиссия).
3. Maintenance margin — плоские 0.5% (у биржи ступенчатые tiers
   по размеру позиции; плоская ставка консервативнее для мелких
   позиций и проще для крупных — см. п. 4).
4. Ступенчатые лимиты плеча по нотионалу не моделируются; потолок —
   `ASTRA_LEVERAGE_MAX` + лестница уверенности + проверка «стоп
   раньше ликвидации».
5. Mark price в бэктесте/ресече на истории = close свечи (истории
   mark price нет в загрузчиках).

## Что НЕ входит в контур

- Спот-данные, спот-комиссии, спот-балансы — удалены из активного контура.
- Реальные ордера — отключены (см. выше). Кандидат на будущие live-тесты —
  swap-тестнет BingX (VST-демо), отдельного этапа и ревью.
- Бэктестер (`paperengine`) пока считает на дефолтном `CostModel()`
  (0.1%/0.1%) — консервативнее перпов, результаты занижены, а не завышены.
