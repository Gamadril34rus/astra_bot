**Автономная торговая система для крипто-фьючерсов BingX (USDT-M), живущая на бесплатных GitHub Actions — без VPS.**
Реальные деньги выключены тройным замком. Всё здесь — обучение и исследование, не финансовая рекомендация.

## Три контура, одна книга правил

| Контур | Что это | Статус |
|---|---|---|
| **Paper** | Симулятор с моделью издержек (старт 2000$) | +33.5% за ~3 недели симуляции (2669.57$ на 13.10; малая выборка — мониторинг, не эдж) |
| **Демо-канарейка (VST)** | Реальный демо-счёт BingX, потолок 100$, счётчик 30 циклов | идёт: 8/30 циклов; каждая сделка с измеренным slip |
| **Реал** | Боевой счёт | **замок**: ZEUS_MAINNET отсутствует в системе; включение = только прямое слово владельца после предусловий |

Правила одинаковы во всех контурах (live = ровно как в бумаге): риск на сделку ≤2%, день ≤4% / неделя ≤6%, HARD_CAP $100, kill-switch n≥5 / PF<1, HALT безусловен, heat-губернатор (3 минуса → риск ×0.5), частички 30/70, стоп на вход после TP1, лестница плеча по уверенности (live-подтверждена), ghost-price guard.

## Как это работает

Внешний планировщик (cron-job.org) дёргает workflow_dispatch каждые 5 минут → раннер делает один цикл
(наблюдения → решения → ордера) → состояние (позиции, сделки, журнал, heat) коммитится на master с retry/autostash.
Параллельность гасится concurrency-группой. VPS не используется — принципиально.

**Качество:** каждый PR проходит gates — pytest + ruff (по изменённым файлам) + import-smoke + интеграционные тесты + лимит роста состояния. Красные gates = мерж невозможен.

**Телеметрия владельцу:** ракеты 🚀 (вход: qty/entry/стоп/тейк, плечо) и 🏁 (выход: точный PnL до цента из филлов биржи — exit, комиссии входа+выхода, slip на входе и выходе; дедуп — одна ракета на событие), своды 09:00/21:00 МСК со сверкой до цента, санитар-строки. Остальное в TG не летит — только факты.

**Аудит:** каждое решение журналируется; сделки без журнала = «брак партии» и в статистику не идут.

## Предусловия реала (всё или ничего)

1. тень клина ≥50 торговых дней без false-retest (~22.10) → решение по стратегии 26.10
2. ≥30 демо-циклов с журналом
3. канарейка VST: 100$ отработали без происшествий
4. сверка денег: demo-vs-реал slip-таблица на одних сигналах
5. СЛОВО владельца — единственный ключ последнего замка
