## Zeus: как работает

Каждые 5 мин внешний планировщик (cron-job.org) дергает workflow_dispatch → раннер делает один цикл по 30 символам (наблюдения + решения) → состояние (позиции, сделки, журнал, статистика) коммитится на master с retry/autostash. Нативный */5 остался запасным, параллельность гасится concurrency-группой.

Статистика стратегий (shrinkage, min 20 сделок) участвует в решениях; слабые бакеты на probation ×0.25.

**Telegram-сигналы** (владелец повторяет сделки ВРУЧНУЮ на площадке челленджа — автоматизация там запрещена правилами): мгновенно — сильные входы (confidence ≥ 0.88, whitelist 23 ликвидных пары) и закрытия; перестановки стопов (только вперёд, шаг ≥0.15%) — в дайджест раз в 2 часа; «всё тихо» — раз в 12 часов.
